# java-lotto-precourse

## ✅ 로또 기본 기능 구현 목록 v1

### 1. 로또 구매 기능

- [x] 구입금액 입력받기
- [x] 입력금액을 1000으로 나눠 로또 발행 개수 계산
- [x] Randoms.pickUniqueNumbersInRange(1, 45, 6)로 로또 번호 생성
- [x] 생성된 로또 번호 오름차순 정렬
- [x] 구매 개수와 로또 번호들 출력

### 2. 당첨 번호 입력 기능

- [x] 당첨 번호 입력받기 (쉼표 기준 파싱)
- [x] 보너스 번호 입력받기

### 3. 당첨 통계 기능

- [x] 각 로또와 당첨 번호 일치 개수 확인
- [x] 2등 판정 (5개 일치 + 보너스 일치)
- [x] 등수별 당첨 개수 집계
- [x] 총 당첨금 계산
- [x] 수익률 계산 (당첨금 / 구입금액 * 100, 소수점 둘째자리 반올림)
- [x] 당첨 통계 출력

### 4. Enum 클래스

- [x] Rank enum (등수, 일치개수, 보너스여부, 당첨금)
